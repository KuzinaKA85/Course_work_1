# Приложение "Анализ банковских транзакций"
## Описание
Курсовая работа, в рамках которой реализовано приложение для анализа транзакций по банковским картам
## Установка
Клонируйте репозиторий: git@github.com:KuzinaKA85/Course_work_1.git
## Установите зависимости:
- `pip install flake8`
- `pip install black`
- `pip install mypy`
- `pip install isort`
- `pip install requests`
- `pip python-doten`
- `pip pandas`
- `pip pytest`
- `pip openpyxl`
## Реализованный функционал
1. Веб страницы: "Главная страница" - главная функция принимает на входстроку с датой и временем. Возвращает JSON-ответ для главной страницы. Содержит приветсвие, информацию по картам, топ 5 транзакций по сумме платежа, курс валют, стоимость акций.

2. Сервиси: "Простой поиск" - Принимает на вход строку для поиска. Возвращает JSON-ответ со всеми транзакциями, содержащими запрос в описании или категории.

3. Отчеты/Траты по категориям - Принимает на вход датафрейм с транзакциями, название категории, опциональную дату. Возвращает траты по заданной категории за последние три месяца (от переданной даты).

## Функции приложения
1. Функция ***get_greeting*** возвращает приветствие "Доброе утро!/Добрый день!/Добрый вечер!/Доброй ночи!" в зависимости от текущего времени.

2. Функция ***read_transactions_xlsx*** для считывания финансовых операций из Excel-файла..

3. Функция ***load_json_data*** возвращает данные о финансовых транзакциях из JSON.

4. Функция ***get_last_four*** возвращает последние четыре символа карты.

5. Функция ***get_cashback*** для подсчёта кешбека.

6. Функция ***filter_by_state*** используется для фильтрации списка словарей по значению ключа 'state'.

7. Функция ***get_card_infos*** возвращает информацию о картах.

8. Функция ***get_top_transactions*** выводит топ-5 транзакций по сумме платежа.

9. Функция ***main_page*** возвращает информацию для главной страницы.
